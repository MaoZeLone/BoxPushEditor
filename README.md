# BoxPush

格子推箱子。人一次走一格，把箱子推到目标上过关。编辑器里可以画关、校验、试玩。

引擎是 Unreal Engine 5.5。打开 `BoxPush/BoxPush.uproject`。第一次会编译 `BoxPush` 和 `BoxPushEditor` 两个 C++ 模块。`.uproject` 里记的是本机引擎，换电脑后在启动器里改选 5.5，再生成工程文件。

启动图是 `Content/Maps/M_Menu`。

## 先玩一局

1. 在编辑器里点播放，或把游戏独立运行起来。不要直接把启动图改成对局图。
2. 主菜单有开始、设置、退出。
3. 开始后进入选关。第 1 关是开着的，后面的关要通关前一关才解锁。
4. 用 WASD 或方向键走。面前是箱子就推一格；面前是墙、空洞，或箱子推不动，人留在原地，这一步不计。
5. 点暂停可以继续、重开，或回选关。通关后可以再玩、进下一关，或回选关。
6. 设置里的主音量会记住。存档只记这一关有没有通关，用来解锁下一关。没有星级，也没有最少步。

重做没绑到输入配置时，按 Y 重做。

## 关卡编辑器

菜单栏 **窗口 → BoxPush 关卡编辑器**。

左边是关卡列表，中间是预览，下面是可放置的内容，右边是详情。可以新建关卡（显示名、ID、宽高 1 到 20），调顺序，保存，删除。

两种模式：

- **普通模式：** 点选格子里的物体，拖到别的格子，或拖坐标轴。Delete 删除。再点当前关卡，右边回到这一关的配置。
- **笔刷模式：** 左键铺地板、墙、空洞、玩家或交互物，按住可拖。右键只擦物体。

工具栏还有试玩、停止、重开、撤销、重做、校验、保存、归位。

校验出 Error 时不能试玩。半成品可以保存，但没上架的关不会出现在选关里。没有 Error 后再上架，正式局才能打到。试玩在这个窗口里进行，不进 PIE，不写通关存档。停止后，关卡回到试玩前的样子。


| 场合   | 操作                              |
| ---- | ------------------------------- |
| 笔刷模式 | 左键铺，右键擦物体，Ctrl+Z / Ctrl+Y       |
| 普通模式 | 左键点选，拖动物体，Delete 删除，右键取消，Ctrl+Z |
| 试玩   | WASD 移动，Z 撤销，Y 重做，R 重开，Esc 停止   |
| 看镜头  | 中键平移，Alt+左键旋转，滚轮缩放，F 或「归位」回到俯视  |


## 箱子和机关

官方内容在 `Content/Data`。

- **普通箱：** 推一次走一格。
- **滑动箱：** 沿推动方向滑到被挡住。
- **返回箱：** 这一步播完回到被推之前的格子。家格被人或其他箱子占着就留在新格。
- **目标：** 要推上去的箱子都在目标上才算过关。人站在目标上不算。
- **踏板：** 箱子压上去会变成按下，推走会弹起。不负责开门，也不改别的物体。
- **地形：** 地板能走，墙和空洞不能走。

同一种物体的规则在定义资产上。某一关里的一只可以改覆盖参数，例如返回箱等多步再回家。没配贴图的物体不画图。

镜头、格子大小和一步的时间在 **项目设置 → Game → BoxPush**。

## 图从哪来

菜单和暂停界面的按钮、字体在 `BoxPush/Asset/UI`，运行时直接读这些 PNG 和 TTF。关卡里的角色和箱子用数据资产上的贴图。`Asset` 里还有 Kenney 的原图，许可是 CC0，见 `BoxPush/Asset/License.txt`。
