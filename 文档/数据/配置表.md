# 配置清单

UE 5.5.4 · 推箱子  
本文只列**策划要填、运行时或编辑器要读**的配置。字段细节仍看三份数据文档。

原则：

- 需要**顺序 / 上架 / 扫描列表**才用 DataTable。现在只有一张：`DT_LevelCatalog`。
- 一种定义一份 DataAsset。交互物、角色、单关都不要再做总表。
- 存档、试玩请求、运行时格子状态**不是配置**，不进 Content。

标记：

- **P0** = 3 天内必须有资产，缺了选关 / 对局 / 12 关交不出
- **P1** = 产品体验补齐，缺了规则还能跑
- **P2** = 明确以后或不做

---

## 0. 总览

按模块看要配什么。`形态` 里 **DT** = DataTable，**DA** = PrimaryDataAsset。

### 关卡

| 优先级 | 资产 | 形态 | 路径 | 谁填 | 干什么 |
|---|---|---|---|---|---|
| P0 | `DT_LevelCatalog` | DT · `FLevelCatalogRow` | `/Game/Data/DT_LevelCatalog` | 编辑器新建关时挂行；上架改 `bListed` | 有哪些关、顺序、上不上选关 |
| P0 | `DA_Level_01` … `12` | DA · `ULevelData` | `/Game/Levels/BuiltIn/` | 关卡编辑器画 | 地形、出生、实例、显示名、推荐步数 |

### 交互物

| 优先级 | 资产 | 形态 | 路径 | 谁填 | 干什么 |
|---|---|---|---|---|---|
| P0 | `DA_Box_Normal` | DA · `UInteractableDef` | `/Game/Interactables/` | 程序先出官方默认，策划可改 Mesh / Steps | 一次推 1 格 |

## 1. 关卡模块

### 1.1 P0 `DT_LevelCatalog`

**唯一一张真正的表。** 选关、解锁、编辑器关列表、下一关只扫它。

行结构 `FLevelCatalogRow`：

| 字段 | 必填 | 说明 |
|---|---|---|
| 行名 | 是 | 等于 `LevelId` |
| `LevelId` | 是 | 存档键。创建后不改 |
| `LevelAsset` | 是 | 软引用该关 `ULevelData` |
| `SortOrder` | 是 | 官方顺序，允许空号 |
| `bListed` | 是 | `true` 才进选关。半成品 `false` |

不存格子、实例、显示名、推荐步数。那些在单关 DA。  
解锁不写本表：列出的第 0 关默认开，其后看存档上一关是否通关。

官方 12 关 = 表里 12 行 + 12 份 DA。不要把 12 关塞进一行。

### 1.2 P0 `ULevelData`（每关一份）

编辑器双击打开的就是它。运行时只读。

必配：`LevelId`、`DisplayName`、`ParMoves`、`Width`/`Height`、`Cells[]`、`PlayerSpawn`、`Instances[]`。  
`DesignerNote` 警告项，能上架。

实例只存 `InstanceId` + `Definition` 软引用 + `Cell`。模型、逻辑去交互物 DA。

## 2. 交互物模块

### 2.1 P0 五份定义 DA

| 资产 | Folder | 最少 LogicComps | 最少 States |
|---|---|---|---|
| `DA_Box_Normal` | Box | Blocking + Pushable(Steps=1) | Idle / Moving |
| `DA_Box_Slide` | Box | + Slide | + Sliding |
| `DA_Box_Return` | Box | + Return | + Returning |
| `DA_Target` | Target | Goal | Idle（Occupied 表现 P1） |
| `DA_Pedal` | Pedal | Pedal | Idle / Pressed |

表现先 `Root(Empty) → Body(Mesh)`，Mesh 可空（引擎方块占位）。

复制一份 DA、增删组件 = 新种类。不要加 Actor 类，不要加总表行。

### 2.2 P1 写在定义里、不新开表

- 目标 Glow：`VisibleInStates = Occupied`
- 滑行拖尾 / 压下音：`UVisualNiagaraComp` / `UVisualAudioComp`（空则跳过）

### 2.3 P2 不配

- `DT_Interactable`、`VisualId`、State Tree 资产
- 事件订阅表（踏板 `EventId` 三天内只切状态，开门以后再订户）
- 墙登记成交互物

## 3. 角色模块

官方四份 DA + IMC，填一次。关卡只写 `PlayerSpawn`。

| 资产 | 必配内容 |
|---|---|
| `DA_Player` | `PawnClass`、三份挂接非空 |
| `DA_InputConfig_Player` | IMC；Native 至少 Move / Undo / Restart |
| `DA_ActionSet_Player` | Move / Push / Undo / Restart / Pause |
| `DA_AbilityTagRelationships_Player` | 前四者被 `Status.StepLocked` 挡；Pause 不进表 |

不要：角色表、`DA_Player_Strong`、把 `Ability.*` 授到身上。

## 4. 表现模块（数据文档里的「另文」）

地形不进交互物。换皮只改这里，不改关卡、不改规则。

### 4.1 P0 `DA_TileVisual`（类还没有，要补）

建议字段，不要做成按格子类型扫的 DT——就三种地形：

| 字段 | 类型 | 说明 |
|---|---|---|
| `FloorMesh` | `TSoftObjectPtr<UStaticMesh>` | 空则引擎方块 |
| `WallMesh` | 同上 | 邻接换变体是 P2，先同一面墙 |
| `EmptyMesh` | 同上 | 通常空，不刷 |
| `CellSize` | `float` | 默认 100 |
| `FloorMaterial` / `WallMaterial` | 可选覆盖 | 可空 |

**不**放 Target / Box / Player。编辑器旧稿把它们写进表现表，已作废。

### 4.2 P1 `DA_Audio`

| 字段 | 何时播 |
|---|---|
| `Move` | 人走进邻格 |
| `Push` | 箱子被推动 |
| `Win` | 胜利 UI |
| `Button` | 菜单按钮 |

四条，用 DA 即可，不要为四个音开 DT。没有资源就留空，运行时跳过。

## 5. 不是配置、不要做成表

| 容易误做成表的 | 实际放哪 |
|---|---|
| 通关、最少步、星级、音量 | `UBoxSaveGame`，键 `LevelId` |
| 试玩「就打这一关」 | GameInstance 内存请求，不写 Content |
| 对局里箱子在哪、`CurrentState` | 地图管理器运行时数据 |
| 解锁顺序 | 总表 `SortOrder` + 存档，无解锁表 |
| 多语言、成就、计时、排行 | 不做 |

---

## 6. 按优先级排期

### P0 — 对局和 12 关

1. Tag + IMC + 角色四份 DA  
2. 交互物五份 DA（Mesh 可空）  
3. `DA_TileVisual`（Mesh 可空）  
4. `DA_Level_01` 手填能过校验  
5. `DT_LevelCatalog` 挂上第 1 行，`bListed=true`  
6. GameInstance / GameMode 指针  
7. 其余 11 关用编辑器画，逐行上架  

### P1 — 看起来像产品

- `DA_Audio` 四个音  
- 目标 / 踏板 `VisualComps` 状态切换  
- 交互物 Niagara / Audio 组件真正播放  

### P2 — 不做

- 事件表、任务表、成就表、本地化表  
- `DT_Interactable`、角色表、解锁表  
- 墙邻接变体表、对象池配置

## 7. 填的顺序（依赖）

```
GameplayTag / IMC
    → DA_Player 套件
    → 五份 InteractableDef          （关卡实例要能指过来）
    → DA_TileVisual                 （能刷出地板墙）
    → DA_Level_01                   （Cells + Instances）
    → DT_LevelCatalog 一行
    → GI.LevelCatalog / GM.DefaultPlayerDef
    → 编辑器再生产 DA_Level_02…12
    →（P1）DA_Audio、Glow
```

总表没有行时，对局仍可读 `StartupLevel` 打第一关；选关列表会是空的。12 关要进选关，必须每关一行且 `bListed=true`。
