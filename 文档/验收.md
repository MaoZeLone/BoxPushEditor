# 验收

对照能玩到的行为，不对照过时设计稿。已知坑的出处：[整体评审](整体评审.md)。

怎么过：每条做一遍，记下过 / 不过。不过的写实际现象。演示前至少把 **A** 和 **D** 跑完。

入口：

- **正式局：** 独立运行或 PIE 打开菜单图（`M_Menu`），不要直接丢进对局图。
- **编辑器：** 打开关卡编辑器窗口（左边选关、中间预览、底下内容浏览器、右边详情）。
- **存档：** 槽 `BoxPushSave`。测「不写档」前先记住当前通关情况，或用干净槽。

## A. 产品主链（必须过）

别人不看工程也能走完这一圈。见 [产品级](需求/产品级.md)。

| # | 测什么 | 做法 | 过 | 不过长什么样 |
|---|---|---|---|---|
| A1 | 能进 | 独立运行进主菜单 | 有开始 / 选关 / 设置 / 退出 | 黑屏、直接进某一关、只能 PIE 开打 |
| A2 | 能选 | 选关列表 | 第 1 关开着；后面的锁着；显示名是中文 | 关卡写死一张、全开或全锁 |
| A3 | 能打 | 进第 1 关，四向走、推一个箱子到目标 | 能走、能推、撞墙原地、步数加 | 人穿墙、推不动、步数不对 |
| A4 | 能胜 | 打完一关 | 出胜利界面：再玩 / 下一关 / 回选关 | 只打一行字还停在关里，或自动退 |
| A5 | 能出 | 暂停 → 回选关；胜利 → 回选关 | 回到选关，不是关编辑器 | 退不出来、退到错误关 |
| A6 | 进度还在 | 通关第 1 关 → 完全退出游戏 → 再进选关 | 第 1 关已通；第 2 关解锁 | 进度丢了；锁没开 |
| A7 | 下一关 | 胜利点下一关 | 进总表里下一关 listed 的那一关 | 跳关、重开本关、没关可去时崩 |
| A8 | 重开 | 对局里重开 | 人、箱回到开局，步数清零 | 箱子还在推过的位置 |
| A9 | 撤销 | 推一步再撤 | 人、箱、步数回到上一步 | 只撤人、不撤箱，或步数乱 |
| A10 | 音量 | 设置里改主音量，关游戏再开 | 立刻有变化，再进仍是这个值 | 只改这一次、不进存档 |

星级、最少步、三星结算：**现在存档只有「是否通关」**。选关没有星、没有最佳步。测 A6 只看通关和解锁，不要拿星级当失败。

## B. 玩法规则

每种官方交互物至少推通一次。编辑器试玩和正式局各做一遍更稳（模拟应一样）。

| # | 测什么 | 做法 | 过 | 不过长什么样 |
|---|---|---|---|---|
| B1 | 普通箱 | 推一次走一格；前方是墙则人不进、箱不动 | 一步一格 | 连滑、穿墙 |
| B2 | 滑动箱 | 沿推动方向一直滑到挡 | 中途有墙/不能进则停；可被另一只箱挡住（默认） | 只走一格、或穿过墙 |
| B3 | 返回箱立刻回 | `DelayMoves=0`，推到空地 | 这一步播完箱子回到推之前的格 | 不回、或人还在动时箱子已经瞬移乱了 |
| B4 | 返回箱回不去 | 家格被另一只箱或人占着 | 箱子留在新格（设计：回不去则不回） | 穿进占用格；或之后永远不再试回家（见 D2） |
| B5 | 目标 | 对类型的箱子叠在目标上 | 占满全部目标才胜；人站在目标上不算 | 人踩目标通关；少一个目标也胜 |
| B6 | 踏板 | 箱子压上去 / 推走 | 状态切 Pressed / 弹起；**不开门、不改别的机关** | 指望开门（那是未做，见 E） |
| B7 | 踏板玩家 | 人站上去、格子上没有箱 | **当前预期：不当压下**（Accept 加载后总是箱子） | 若你改成「人也能踩」，这里要反过来 |
| B8 | 墙 / 空洞 | 走向墙、走向 Empty | 忽略，不当一步，步数不加 | 走进墙或掉出地图还计数 |
| B9 | 不能推 | 面对墙、或无 Push 能力 | 原地，不当有效步 | 人走进箱子格 |
| B10 | 同格叠 | 目标 + 箱子一格 | 能叠；两个阻挡物不能叠（编辑器校验应报错） | 两个箱子叠在同一格还能走 |

## C. 编辑器主链

| # | 测什么 | 做法 | 过 | 不过长什么样 |
|---|---|---|---|---|
| C1 | 开窗 | 打开关卡编辑器 | 左关卡、中预览、下内容、右详情；能拖分栏 | 缺块、点不动 |
| C2 | 换关 | 左边点另一关 | 预览和详情换成那一关 | 还显示上一关 |
| C3 | 画地形 | 铺地板 / 墙 / 空洞，单击和拖拽 | 格子立刻变；所见即所得 | 点不下去、拖出一串错格 |
| C4 | 放交互物 | 从内容浏览器放普通箱、目标、踏板 | 场景里出现对应图 | 空白、或放成 3D 方块 |
| C5 | 玩家 | 放 / 改出生点 | 只有一个玩家位置 | 两个出生点、或玩家站墙上 |
| C6 | 橡皮 | 擦箱子再擦地板 | 实例没了；地变成空洞 | 擦不掉、或把整关清空 |
| C7 | 详情 | 点箱子看覆盖参数（如 DelayMoves） | 改了试玩生效 | 面板能改、试玩仍用 DA 默认 |
| C8 | 校验 | 故意：箱子数 ≠ 目标数，点校验 / 试玩 | 中文 Error；**有 Error 不能试玩** | 仍能试玩；或只 Warning |
| C9 | 半成品能存 | 有 Error 时保存 | 能存盘；选关看不到未上架关 | 存不了；或坏关出现在玩家选关 |
| C10 | 上架 | 无 Error 后上架 / listed | 选关能扫到；正式局能打这一关 | 只有编辑器里有 |
| C11 | 试玩 | 校验过 → 试玩，通关 | 窗口里能走能胜；状态写「不写档」 | 进了 PIE；或正式存档被改（D5） |
| C12 | 停试玩 | 停止 | 回到编辑，关卡数据和停之前一样 | 箱子被试玩推走后写回 DA |
| C13 | 编辑撤销 | 铺一格墙，用编辑器撤销（不是引擎 Ctrl+Z 预期） | 墙没了 | 和 Content Browser Undo 抢；或撤到别的资产 |
| C14 | WASD | **没试玩**时在视口按 WASD | 应能转/移相机（评审：现在会被吞掉，见 D4） | 键没反应、只能鼠标转 |
| C15 | 试玩键 | 试玩中 WASD / 方向键 | 人走；停试玩后不再走路 | 停了还在进输入；或试玩走不了 |
| C16 | 贴图空 | 临时清掉某个箱子 DA 的贴图槽，预览/试玩 | 那个箱子不画，不要冒出默认 Kenney 图 | 没配图仍画出木箱 |

内容浏览器应是数据驱动：官方五种 + 地形出现在树里。不要出现已删的「工具」分类。

## D. 已知问题（专门去戳）

这些是评审里还在或容易回潮的。过了就标「已修」；不过就当演示雷区。

| # | 问题 | 怎么复现 | 失败时 |
|---|---|---|---|
| D1 | 缺定义仍开打 | 关卡实例指向一个不存在的 `DefinitionId`，从选关进正式局（不要走编辑器试玩） | 少箱子仍能玩、仍能按残局判胜。应拒绝开局或当 Error |
| D2 | 返回箱回家失败清计时 | 返回箱 `DelayMoves=0`，推开后家格被另一只箱占住；再把占住的箱子推开 | 家空了返回箱也不再回家 |
| D3 | 正式局不跑校验 | 做一关：Pushable ≠ Goal，上架绕过或直接 PIE 进对局图 | 坏关能开打。编辑器试玩应仍拦住 |
| D4 | 非试玩吞 WASD | 编辑模式点预览，按 WASD | 相机不动。只在试玩时这些键才该走路 |
| D5 | 试玩写档 | 记一下第 1 关是否已通。打开未通关的关试玩并通关，完全退出再进选关 | 试玩把该关标成已通 / 解锁了下一关 |
| D6 | 打开工程弄脏 DA | 关编辑器前 Source Control 干净。只打开工程和关卡编辑器，不改任何东西 | `DA_Box_*`、`DA_ActionSet_Player` 等变脏 |
| D7 | 官方箱子状态被加载改掉 | 给 `DA_Box_Normal` 加一个非 Idle 状态，保存，重开编辑器 | 状态没了，只剩 Idle（旧 `PostLoad` 行为；现应还在） |
| D8 | 两份步时 | 只改 `ABoxMatchWorld::StepDuration`（或默认 0.36），推箱子看人和箱 | 人走完箱子还在滑，或箱子先到人还在插值 |
| D9 | FireEvent 假接 | 踏板 OnEnter 配 FireEvent，打日志看 | 只有 log，门/别的实例不变。不要当功能验收过 |
| D10 | EventId 覆盖 | 实例上改踏板 `EventId`，试玩 | 面板能存；对局不读。不要当「改了就连锁」 |

D6、D7 看 Content 是否脏、DA 字段是否还在，不看玩法手感。

## E. 不要拿来当验收项

这些文档或 DA 备注里像有，代码没有或故意没做。测到「没有」不算失败；演示时不要说有。

- 星级、最少步、按 `ParMoves` 打 1–3 星
- 踏板开门、关卡事件订户、任务编辑器
- 3D `VisualComps` / `DA_TileVisual` 改了画面跟着变（对局是 2D 精灵）
- 改 `DefaultCameraAsset` 或 `UPlayerMoveLogic::StepDuration` 改变对局镜头/步时
- 编辑器试玩出现正式局那套暂停/胜利 UMG
- 12 关、教程、多语言、游戏内画关

口头口径（演示用）：画面是 2D；踏板只切状态；存档只有通关；试玩在编辑器窗口里，不进 PIE，不写档。

## 建议顺序

1. A1–A10 独立运行走主链  
2. B 用内置关或临时关覆盖三种箱子 + 目标 + 踏板  
3. C 新建一关 → 校验拦住 → 修好 → 试玩不写档 → 上架后从选关打到  
4. D1、D2、D5 必测；D4、D6 演示前看一眼
