## 配上最小关卡官方数据

- **修改的内容：** 按代码默认路径写入 Content：角色 `/Game/Characters/DA_Player`（含 InputConfig / ActionSet / Relation / IMC / IA_*）、五种官方交互物、`DA_Level_01`（8×8 墙圈、人(2,3) 箱(3,3) 目标(5,3)、三步 par）、`DT_LevelCatalog` 的 `LV_01` 行。删掉旧的 `/Game/Data/Characters|Interactables|Levels` 副本。`DefaultEngine.ini` 的 `LevelCatalog` 本来就指向这份总表。
- **为什么修改：** GameMode / GI 已经按这些路径加载，磁盘上没有对应 DA，PIE 打不进最小关。
- **好处是什么：** 编辑器里按 Play 就会刷第一关棋盘；WASD 推箱子、Z 撤销、R 重开、Esc 暂停已经绑在 IMC 上。
- **涉及文件：** `BoxPush/Content/Characters/`、`BoxPush/Content/Interactables/`、`BoxPush/Content/Levels/BuiltIn/DA_Level_01.uasset`、`BoxPush/Content/Data/DT_LevelCatalog.uasset`

## 主音量改用 5.5 现用 API

- **修改的内容：** `UBoxGameInstance::ApplyMasterVolume` 不再调用已无实现的 `FAudioDevice::SetTransientMasterVolume`，改为 `SetTransientPrimaryVolume`。
- **为什么修改：** 5.5 头文件还留着旧函数声明，实现已删；链接时报 LNK2019，编不过编辑器模块。
- **好处是什么：** Development Editor 能链上，设置里的主音量可以真正打到音频设备。
- **涉及文件：** `BoxPush/Source/BoxPush/Private/Game/BoxGameInstance.cpp`

## 引擎目录改成带空格的默认名

- **修改的内容：** 本机引擎父目录从 `EpicGames` 改成 `Epic Games`；`UECommon.props`、`BoxPush.vcxproj` 里的 Build.bat / OutDir / 头文件路径同步改到带空格路径，并建好 Makefile 用的 `Engine/Intermediate/Build/Unused`。
- **为什么修改：** 解决方案本来就按启动器默认的带空格路径找 UBT；文件夹改名后工程文件还在写旧名，MSBuild 会在 Program Files 下新建 `EpicGames` 而被拒绝（MSB3191）。
- **好处是什么：** 编译、启动器、解决方案都走同一条带空格路径，不再因为目录名差一个空格找不到工程或写不进中间目录。
- **涉及文件：** `BoxPush/Intermediate/ProjectFiles/UECommon.props`、`BoxPush/Intermediate/ProjectFiles/BoxPush.vcxproj`

## 技术策划案按系统拆文件

- **修改的内容：** 新增 `文档/技术策划/`，一个大系统一份 md（地图管理器、格子模拟、流程、交互物、角色 3C、地形、表现、事件、存档、UI、校验、关卡编辑器），文内固定写职责 / 功能 / 参数；总索引和 `设计/系统` 补上入口。
- **为什么修改：** `设计/系统` 只回答有哪些系统，字段散在数据文档里，对着单个系统工作时要对着好几份翻。
- **好处是什么：** 技术策划改某一系统时只打开对应 md，就能看到管什么、有哪些能力和可配参数。
- **涉及文件：** `文档/技术策划/`、`文档/README.md`、`文档/设计/系统.md`

## 修改记录改为按天分文档

- **修改的内容：** 日志从单文件 `文档/修改记录.md` 改成目录 `文档/修改记录/YYYY-MM-DD.md`；skill 改为写入当天文件，新的一天要在目录索引补链接。
- **为什么修改：** 所有日期挤在一份里会越来越难翻，需要对着某一天回看。
- **好处是什么：** 按天打开即可，当天条目短、历史互不干扰。
- **涉及文件：** `.cursor/skills/change-log/SKILL.md`、`文档/修改记录/README.md`、`文档/修改记录/2026-09-22.md`、`文档/README.md`
