# 文档

UE 5.5.4 · 推箱子  
字段、路径、谁准：以 **数据/** 为准。系统职责看 **设计/系统**。每个系统的职责 / 功能 / 参数看 **技术策划/**。编辑器交互看 **设计/关卡编辑器设计**（文首有和数据文档的对齐说明）。

```
文档/
  修改记录/     按天：改了什么、为什么、好处
  需求/         题目、原始开发记录
  设计/         系统拆分、功能清单、关卡编辑器、细节面板排版
  数据/         关卡 / 交互物 / 角色字段；配置清单
  技术策划/     一个大系统一份：职责、功能、参数
```

| 文件 | 回答什么 |
|---|---|
| [修改记录](修改记录/README.md) | 按天：改了什么、为什么改、好处是什么 |
| [整体评审](整体评审.md) | 设计和实现对不上的地方、演示前要处理的问题 |
| [验收](验收.md) | 交出去前要手测哪些：主链、玩法、编辑器、已知坑 |
| [需求/题目](需求/题目.md) | 笔试要求 |
| [需求/开发记录](需求/开发记录.md) | 当时怎么想的，不是定稿 |
| [设计/系统](设计/系统.md) | 会写哪些代码系统 |
| [设计/开发规划](设计/开发规划.md) | 按什么顺序做功能 |
| [设计/功能清单](设计/功能清单.md) | 交互物、角色已经提供什么 |
| [设计/关卡编辑器设计](设计/关卡编辑器设计.md) | Slate 编辑器做什么 |
| [设计/细节面板排版](设计/细节面板排版.md) | 右侧细节面板的字号和分组 |
| [技术策划/](技术策划/README.md) | 每个大系统的职责、功能、参数 |
| [数据/关卡数据](数据/关卡数据.md) | `DT_LevelCatalog` + `ULevelData` |
| [数据/交互物数据](数据/交互物数据.md) | `UInteractableDef` |
| [数据/角色数据](数据/角色数据.md) | `UPlayerDef` 及挂接 |
| [数据/配置表](数据/配置表.md) | 预期要配哪些表 / DA，按模块和优先级 |

阅读顺序：题目 → 系统 → 技术策划（按系统）→ 三份数据 → 配置表 → 开发规划 → 功能清单 → 编辑器。
