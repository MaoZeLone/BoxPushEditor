# 开发规划

UE 5.5.4 · 推箱子 · 3 天  
按依赖排功能，前面断了后面空转。字段看 [数据](../数据/关卡数据.md)，系统职责看 [系统](系统.md)，要配哪些资产看 [配置表](../数据/配置表.md)。

原则：

- 先让**一关能玩**，再套流程 UI，再做编辑器。编辑器复用对局那套刷 Mesh，不要先做工具。
- 新箱子种类 = 新 DA，不加 Actor 类、不加总表。
- 每天结束必须有一个能打开演示的点，不堆到最后再接。

## 1. 总顺序

```
① 官方资产最小集
        ↓ 没有 DA，C++ 空转
② 对局最小闭环（1 人 1 普通箱 1 目标）
        ↓ 规则真的能跑
③ 局外流程 UI + 存档
        ↓ 产品级「能进能出」
④ 其余箱子（滑 / 回 / 踏板）各做一关验证
        ↓
⑤ 地形表现表（预览和对局同一套）
        ↓
⑥ 关卡编辑器 P0（画、校验、试玩）
        ↓
⑦ 用编辑器交 12 关
        ↓
⑧ P1 抛光（音效、Glow、编辑器点选）
```

不要把 ⑥ 提到 ② 前面。不要在 ② 没过的时候铺 12 关。

## 2. 分阶段

### ① 官方资产最小集 — 先填能加载的东西

**做什么**

1. IMC + 四个 IA（Move / Undo / Restart / Pause）
2. `DA_Player` 四件套（PlayerDef / InputConfig / ActionSet / Relation）
3. 五份交互物 DA（Mesh 可空）
4. `DA_Level_01`：默认 8×8、1 人 1 普通箱 1 目标
5. `DT_LevelCatalog` 一行，`bListed=true`
6. GameInstance / GameMode 指针指到这些资产

**完成标准：** Content 里能双击开到这些资产；PIE 进对局图不再因为 Level 为空直接失败。

---

### ② 对局最小闭环 — 规则验收

**已有代码，本阶段是验，不是重写。**

要亲手过一遍：

- WASD 走格，墙忽略
- 朝箱子再走一步即推，一次 1 格
- 箱子上目标即胜（现在是屏幕字 + 写档）
- Z 撤销、R 重开
- 一步插值期间走/推/撤被 `StepLocked` 挡住

**完成标准：** 不打开编辑器、不经过选关，PIE 直接打 `DA_Level_01` 能通关。这是 D1 中午前必须过的门。

卡住就查：资产没配 / `InitFromLevel` 失败 / InputConfig 没绑上。不要回头改数据结构。

---

### ③ 局外流程 UI — 产品级进出

对局规则已经在 GameMode / GameInstance 上，UI 只消费，不重写模拟。

顺序（先主链，再设置）：

1. 对局 HUD：步数、暂停键入口
2. 胜利：再玩 / 下一关 / 回选关；显示星级
3. 暂停：继续 / 重开 / 回选关
4. 选关：扫 `DT_LevelCatalog` 的 `bListed`；未通关下一关锁定；星级
5. 主菜单：开始、设置、退出
6. 设置：主音量（GI 已有 `SetMasterVolume`）

试玩标记：编辑器进来的对局不写档（代码已有，UI 标「试玩」即可）。

**完成标准：** 主菜单 → 选关 → 打一关 → 胜利回选关，进度还在。没有选关图时，先 HUD + 胜利也能演示。

---

### ④ 其余箱子 — 各一关验证

模拟已吃 Slide / Return / Pedal。本阶段只配关、验手感。

| 顺序 | 关 | 验什么 |
|---|---|---|
| 先 | `DA_Level_02` 滑行箱 | 推到底；前方箱子能挡住 |
| 再 | `DA_Level_03` 回程箱 | 推完回原位；撤销先撤人再清回程 |
| 后 | `DA_Level_04` 踏板 | 压下切 Pressed；**不开门** |

总表挂上，`bListed` 按校验过才 true。

**完成标准：** 四种官方箱子各至少一关能通；踏板只看状态，不接 `EventId` 订阅。

---

### ⑤ 地形表现表 — 给编辑器铺路

新建 `DA_TileVisual`（类还没有）：`FloorMesh` / `WallMesh` / `CellSize`。  
`ABoxMatchWorld` 刷地形改读这份，空则仍用 Cube。

箱子 / 目标 / 踏板继续走 `VisualComps`。玩家继续走 `PawnClass`。

**完成标准：** 换 Mesh 只改这一份 DA，对局立刻变；编辑器预览将复用同一函数，不要再写第二套生成。

---

### ⑥ 关卡编辑器 P0

独立 Editor 模块，不进包。交互见 [关卡编辑器设计](关卡编辑器设计.md)。

必须按这个内部顺序做：

1. 预览 Actor：调用运行时同一套刷 Mesh（⑤ 的函数）
2. 新建关：默认一圈墙、1 人 1 箱 1 目标，挂进总表 `bListed=false`
3. 笔刷：地板 / 墙 / 箱子 / 目标 / 玩家 / 橡皮（先 EUW 网格也行，视口必须出模型）
4. 校验面板：错误中文列出；有错不能上架、不能试玩，DA 仍可存
5. 试玩：校验过 → PIE 走正式 GameMode；停了回到本窗口；不写档

**完成标准：** 不写代码、只开 UE，能新建一关、改两格、校验拦住「两个玩家」、试玩规则和正式对局一致。

P1（有空再做）：视口点选绘制、错误点到格子高亮、死角警告。P2 不做。
