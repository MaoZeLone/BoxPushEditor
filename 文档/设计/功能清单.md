# 功能清单 · 交互物 / 角色

UE 5.5.4 · 推箱子  
只列这两块会提供什么能力。关卡表、选关 UI、关卡编辑器、存档见 [系统](系统.md)。  
数据结构见 [交互物数据](../数据/交互物数据.md)、[角色数据](../数据/角色数据.md)；要配哪些表见 [配置表](../数据/配置表.md)。

标记：

- **数据** = DA 里能配
- **运行时** = 对局已经吃这份配置
- **未做** = 文档有，代码还没有

## 1. 交互物

场景里同一种 Actor。换种类只换 `UInteractableDef`，不加新 Actor 类。墙 / 地板不是交互物。

### 1.1 框架

| 功能 | 状态 | 说明 |
|---|---|---|
| 关卡实例指向一份定义 | 数据 | `FBoxLevelInstance`；现用 `DefinitionId`，文档要软引用 |
| 一种定义一份 DA | 数据 | `DA_Box_Normal` 等，`DefinitionId` 创建后不改 |
| 调色板按 Folder 分组 | 数据 | `Box` / `Target` / `Pedal`。编辑器扫 Asset Registry 未做 |
| 表现、逻辑两套 Instanced 数组 | 数据 + 运行时 | 有就生效，没有 `bEnabled` |
| 自己的 `States[]`，不挂 State Tree | 数据 + 运行时 | 模拟事件切 `CurrentState` |
| 逻辑不读当前状态决定能不能推 | 运行时 | 地形 + Blocking 才是玩法真相 |
| 同一格可叠（目标 + 箱子） | 运行时 | 两个 Blocking 不应叠，运行时未单独报错 |
| 新机制 = 新组件类丢进数组 | 数据 | 不加新 DA 类、不加新 Actor 类 |

### 1.2 官方五种

| 定义 | Folder | 功能 | 状态 |
|---|---|---|---|
| `DA_Box_Normal` | Box | 一次推 `Steps` 格（官方 1） | 数据 + 运行时 |
| `DA_Box_Slide` | Box | 沿推动方向滑到停；前方箱子可挡住 | 数据 + 运行时 |
| `DA_Box_Return` | Box | 推完回推之前的格子；`DelayMoves` 可延后 | 数据 + 运行时 |
| `DA_Target` | Target | 不挡人、不挡箱；上面叠对 Folder 的箱子算入胜 | 数据 + 运行时 |
| `DA_Pedal` | Pedal | 被箱子（或配置允许的对象）压下，切 Pressed | 数据 + 运行时（只切状态） |

复制一份 DA、增删组件 = 新箱子。不要做 `DA_Player_Strong` 这种角色变体去改推力。

### 1.3 逻辑组件（格子模拟读这些）

| 组件 | 功能 | 状态 |
|---|---|---|
| `UBlockingLogic` | `bBlocksPlayer` / `bBlocksPush` | 运行时 |
| `UPushableLogic` | 人朝它再走一步则推；`Steps` 一次连走，中途挡则停 | 运行时 |
| `USlideLogic` | 忽略 `Steps`，滑到不能进；可 `bStopOnBox` | 运行时 |
| `UReturnLogic` | 记录这一步开始时的格子；0 = 本步表现完立刻回 | 运行时 |
| `UGoalLogic` | `RequiredFolder` 谁停上面算入胜；全目标占满则通关 | 运行时 |
| `UPedalLogic` | 压下/弹起发 `Pressed` / `Released`；`EventId` 留给事件系统 | 状态有，事件订阅未做 |

Slide / Return 必须同时有 Pushable。校验数据层有，进关未再跑一遍。

### 1.4 表现与状态

| 功能 | 状态 | 说明 |
|---|---|---|
| `VisualComps` 按 ParentId 建树 | 运行时 | Empty / Mesh；Mesh 空则用引擎方块 |
| `VisibleInStates` | 运行时 | 空 = 全显示 |
| 格子移动短插值 | 运行时 | 逻辑已落格再播 |
| Niagara / Audio 组件 | 数据有字段 | 空则跳过，未接播放 |
| Skeletal Mesh 组件 | 数据有字段 | 交互物官方不用 |
| 模拟事件切状态 | 运行时 | `Pushed` `Arrived` `Blocked` `SlideStart` `Returned` `Pressed` `Released` |
| 目标 Occupied / 踏板 Pressed 表现 | 部分 | 状态会切；Glow / 变色未做 |

官方最小树：`Root(Empty) → Body(Mesh)`。

### 1.5 交互物先不做

- 每种箱子一个蓝图 Actor
- State Tree / `VisualId` / `DT_Interactable`
- 逻辑组件读 `CurrentState` 挡推
- 把墙登记成交互物
- 踏板开门、连锁（`EventId` 先发后接）
- Mass / Smart Object
- 对象池

## 2. 角色

角色不扩展：没有角色表、关卡不选人。人不是交互物，不进 `Instances`。不上 GAS。

### 2.1 生成与 3C 挂接

| 功能 | 状态 | 说明 |
|---|---|---|
| GameMode 挂一份 `DA_Player` | 运行时 | 关卡只写 `PlayerSpawn` |
| `PawnClass` 刷人 | 运行时 | 默认 `ABoxPlayerCharacter` |
| Character 薄壳 | 运行时 | 不写「能不能推」 |
| 弹簧臂 + 相机 | 运行时 | 不接 CameraAsset |
| 占位 Mesh | 运行时 | 几何体；骨骼动画未接 |

### 2.2 输入

| 功能 | 状态 | 键（官方 IMC） |
|---|---|---|
| 按键只发 Tag | 运行时 | InputConfig Native 表 |
| 走格 | 运行时 | WASD → `InputTag.Move` |
| 撤回 | 运行时 | Z → `InputTag.Undo` |
| 重开 | 运行时 | R → `InputTag.Restart` |
| 暂停 | 运行时 | Esc → `InputTag.Pause` |
| 长按连走（一步播完再走） | 运行时 | StepLocked 解开后继续 |

没有 Ability 输入表。推不绑键。

### 2.3 能力赋予（填表，不授 Tag）

有没有某操作 = `DA_ActionSet_Player.GrantedActions[]` 有没有这一行。  
**不要把 `Ability.*` 拷到角色 OwnedTags。**

| 行 | InputTag | 做什么 | 状态 |
|---|---|---|---|
| `Ability.Move` | `InputTag.Move` | 向邻格走一步 | 运行时 |
| `Ability.Push` | 空 | 朝 Pushable 再走一步即推 | 运行时 |
| `Ability.Undo` | `InputTag.Undo` | 撤上一步格子 | 运行时 |
| `Ability.Restart` | `InputTag.Restart` | 本关从头刷 | 运行时 |
| `Ability.Pause` | `InputTag.Pause` | 暂停/继续模拟输入 | 运行时（无暂停 UI） |

推动差异做在箱子 LogicComps 上，不做第二份 PlayerDef。

### 2.4 当前能不能发（Relation + 身上状态）

查法：`CanPerform` = ActionSet 有行 **并且** Relation 允许。

| 功能 | 状态 | 说明 |
|---|---|---|
| `Status.StepLocked` 挡 Move / Push / Undo / Restart | 运行时 | 一步插值期间 |
| Pause 不进 Relation 表 | 运行时 | 随时能开（仍要 ActionSet 有 Pause 行） |
| `State.Walking` / `State.Pushing` | 运行时 | 给动画读；Idle = 两个都没有 |
| 格子能不能落 | 运行时 | 地形 + Blocking，不用 Tag 判断墙 |

身上 `OwnedTags` 只放 `State.*` / `Status.*`。

### 2.5 走和推（角色侧约定）

| 功能 | 状态 | 说明 |
|---|---|---|
| 按格子走，不是连续位移 | 运行时 | 一次输入一步 |
| 推是「朝箱子再走一步」 | 运行时 | 人只动一格；箱子走 Steps / 滑行 |
| 墙 / 空洞忽略 | 运行时 | 不发步 |
| 推不动（前方不可进） | 运行时 | 人不移动；箱子可进 `Blocked` |

### 2.6 角色先不做

- GAS / ASC / GA / GE / AttributeSet
- 把 `Ability.*` 授到 OwnedTags
- 多角色、换人、角色表
- 把玩家登记成交互物；套 VisualComps / LogicComps / `States[]`
- 体力、跳、冲刺、F 键世界交互
- 骨骼动画、CameraAsset
- 暂停菜单 / 胜利 UI（流程系统，不在角色上）

## 3. 两条链不要接错

```
角色：键 → InputTag → ActionSet 行 → Relation → 格子模拟
交互物：LogicComps 回答这一步结果 → 发模拟事件 → States 切 CurrentState → VisualComps 显示
```

格子能不能走看地图。这一步人能不能发看角色。箱子滑不滑、回不回看交互物定义。
