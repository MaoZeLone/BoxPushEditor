# 角色 3C · 技术策划案

代码：`UPlayerDef`、`ABoxPlayerCharacter`  
角色不扩展：没有角色表，关卡不选人。人不是交互物，不上 GAS。推动差异做在箱子上。

---

## 职责

**管**

- 按键只发 InputTag
- 有没有某操作（ActionSet 有没有这一行）
- 当前能不能发（Relation + 身上 `State.*` / `Status.*`）
- 把「方向 + 是否允许推」交给格子模拟
- 一步期间打 `Status.StepLocked`，播完再摘

**不管**

- 前方是墙还是箱子（[地图管理器](地图管理器.md) / [格子模拟](格子模拟.md)）
- 箱子滑不滑、回不回
- 暂停菜单、胜利 UI

公式：

`CanPerform(Ability) = ActionSet 有行 并且 Relation 允许。`

**不要把 `Ability.*` 授到身上。** 身上只放 `State.*` / `Status.*`。

---

## 功能

```
WASD → InputTag.Move → 请求走一步
         ├ CanPerform(Move) 不过 → 整步丢掉
         └ CanPerform(Push) → 记成 bCanPush，仍把步交给棋盘
```

Push **不绑键**。推是「朝箱子再走一步」。

官方 Relation：`Status.StepLocked` 挡住 Move / Push / Undo / Restart。Pause 不进 Relation，随时能开。

一步开始授 `State.Walking` 或 `State.Pushing`，并锁 StepLocked；插值结束全摘。Idle = 两个 State 都没有。

## 参数

### `UPlayerDef`（`/Game/Characters/DA_Player`）

| 参数 | 类型 | 说明 |
|---|---|---|
| `PlayerId` | FName | 默认 `Player`，资产名 `DA_Player` |
| `DisplayName` | FText | |
| `DesignerNote` | FString | |
| `PawnClass` | TSubclassOf\<APawn\> | 默认 `ABoxPlayerCharacter` |
| `InputConfig` | `UBoxInputConfig` | IMC + Native 表 |
| `ActionSet` | `UBoxActionSet` | 有哪些操作 |
| `TagRelationshipMapping` | Relation DA | 当前能不能发 |

关卡只写 `PlayerSpawn`，不引用这份 DA。GameMode 挂它。

### InputConfig Native 行 `FBoxInputAction`

| 参数 | 说明 |
|---|---|
| `InputAction` | IA 资产 |
| `InputTag` | 按键发出的 Tag |

另：`DefaultMappingContext` = `IMC_Player`。

官方键：WASD → Move；Z Undo；R Restart；Esc Pause。

### ActionSet 行 `FBoxGrantedAction`

| 参数 | 说明 |
|---|---|
| `AbilityTag` | 操作身份，Relation 按这个查 |
| `InputTag` | 对应输入；**空 = 不绑键**（官方 Push） |

官方五行：

| AbilityTag | InputTag |
|---|---|
| `Ability.Move` | `InputTag.Move` |
| `Ability.Push` | 空 |
| `Ability.Undo` | `InputTag.Undo` |
| `Ability.Restart` | `InputTag.Restart` |
| `Ability.Pause` | `InputTag.Pause` |

### Relation 行 `FBoxAbilityTagRelationship`

| 参数 | 说明 |
|---|---|
| `AbilityTag` | 哪条操作 |
| `ActivationRequiredTags` | 身上必须有 |
| `ActivationBlockedTags` | 身上不能有 |
| `AbilityTagsToBlock` / `ToCancel` | 预留，对齐 Lyra；官方走/推不用 |

官方：Move / Push / Undo / Restart 的 `ActivationBlockedTags` = `Status.StepLocked`。

### 身上会有的 Tag（运行时，不配表）

`State.Walking`、`State.Pushing`、`Status.StepLocked`。
