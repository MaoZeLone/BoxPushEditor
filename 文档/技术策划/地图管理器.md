# 地图管理器 · 技术策划案

代码：`UBoxBoard`  
进关加载 `ULevelData` 之后，谁问格子都找它。运行时格子状态活在这里，不写回关卡资产。

---

## 职责

**管**

- 这一格是空 / 地板 / 墙
- 这一格叠了哪些实例
- 某方向邻格
- 可不可站（地形）、挡不挡人 / 挡不挡箱（Blocking）
- 人在哪、每个实例在哪

**不管**

- 这一步怎么走、怎么推（[格子模拟](格子模拟.md)）
- 胜负、撤销栈、暂停
- 刷哪张 Mesh（[程序化地形](程序化地形.md)）
- UI

---

## 功能

| 功能 | 说明 |
|---|---|
| 进关加载 | `InitFromLevel`：拷宽高、`Cells`、出生点、解析每个实例的 `Definition` |
| 地形查询 | 矩形内按 `Index = Y * Width + X`；界外当 Empty |
| 占位查询 | `GetInstancesAt`、`FindInstance` |
| 阻挡查询 | 扫该格实例的 `UBlockingLogic` |
| 可推物查询 | `HasPushableAt`、`FindPushableBlockingPlayer`（挡人且带 Pushable） |
| 双 Blocking 警告 | 同一格两个阻挡实例，进关打 Warning；上架由校验拦 |

没有单独的逻辑组件注册表。查询直接读实例上的 `Def->FindLogic`。

## 参数

### 读自关卡资产 `ULevelData`

| 参数 | 类型 | 范围 / 默认 | 说明 |
|---|---|---|---|
| `Width` / `Height` | int32 | 5–20，默认 8 | 地图矩形 |
| `Cells[]` | `ETerrainCell` | 长度 = W×H | Empty 不能站；Floor 可站；Wall 不能进 |
| `PlayerSpawn` | FIntPoint | 必须在 Floor 上 | 出生格，恰好 1 个 |
| `Instances[]` | `FBoxLevelInstance` | 可叠格 | 箱子 / 目标 / 踏板 |

`FBoxLevelInstance`：

| 参数 | 类型 | 说明 |
|---|---|---|
| `InstanceId` | FName | 本关唯一 |
| `Definition` | 软引用 `UInteractableDef` | 主引用 |
| `DefinitionId` | FName | 软引用为空时的回退 |
| `Cell` | FIntPoint | 出生格 |
| `YawSteps` | int32 | 0–3，推箱子暂不用 |

### 运行时（不进资产）

| 参数 | 说明 |
|---|---|
| `PlayerCell` | 人当前格，模拟改它 |
| 实例 `Cell` | 箱子当前格 |
| 实例 `CurrentState` | 表现阶段，模拟改、Board 只存 |
| `ReturnHome` / `MovesUntilReturn` | 回程用，存在实例上 |

### 世界换算（现写死）

| 参数 | 值 | 说明 |
|---|---|---|
| `BoxGrid::CellSize` | 200 | 一格边长（cm） |
| `BoxGrid::OriginZ` | 200 | 格子平面高度 |

将来 `DA_TileVisual.CellSize` 应接到这里，现在对局不读那份表。
