# 关卡编辑器 · 技术策划案

独立 Editor 模块，Slate 资产编辑器，**不进包**。  
只读写和运行时同一份 `ULevelData`。不实现第二套推箱子规则。

详细交互见 [关卡编辑器设计](../设计/关卡编辑器设计.md)。本文只定职责、功能和会改哪些参数。

代码：**尚未做。**

---

## 职责

**管**

- 预览（复用对局刷 Mesh）
- 笔刷改地形 / 实例 / 出生点
- 调色板、校验面板、试玩入口
- 新建关：创建 DA + 总表加一行 `bListed=false`

**不管**

- 游戏内画关、分享、自定义关
- 第二种模拟
- 进包的调试面板（对局 HUD 的试玩标记可以进）

合不合法由 [校验](校验.md) 拦；好不好玩由策划 PIE。

---

## 功能

| 块 | 干什么 |
|---|---|
| 预览 | 视口刷和运行时同一套：地形读 TileVisual，交互物读 VisualComps，人读 PawnClass |
| 笔刷 | 点击单放，按住拖连续画；橡皮右键 |
| 调色板 | Asset Registry 扫 `UInteractableDef`，按 `Folder` 分组 |
| 校验面板 | 列出错误；点一条高亮对应格（P1） |
| 试玩 | 校验过 → PIE 走正式 GM；停了回本窗口；**不写档** |
| 撤回 | 先走 UE 资产 Dirty / Ctrl+Z；笔刷级 Undo 是 P1 |
| 保存 | 先写 DA，跑校验，再改总表该行 `bListed` |

官方关：`Content/Levels/BuiltIn/`。半成品不要混进选关（`bListed=false`）。

新建默认：8×8 外墙内地板；`PlayerSpawn=(2,3)`；普通箱 `(3,3)`；目标 `(5,3)`。

---

## 参数

编辑器改的就是关卡资产字段，不另开一层：

### 关卡

| 参数 | 谁改 |
|---|---|
| `Width` / `Height` | 细节；裁到出生点或实例要先确认 |
| `Cells[]` | 地板 / 墙 / 橡皮笔刷 |
| `PlayerSpawn` | 玩家笔刷（恰好 1） |
| `Instances[]` | 箱子 / 目标 / 踏板笔刷 |
| `DisplayName` / `ParMoves` / `DesignerNote` | 细节面板 |
| `LevelId` | 创建后不改 |

### 总表该行

| 参数 | 谁改 |
|---|---|
| `LevelAsset` | 新建时挂上 |
| `SortOrder` | 新建 = 当前最大 +1 |
| `bListed` | 校验通过才允许 true |

调色板不写总表。新交互物种类 = 新 DA，扫 Asset Registry 即出现。
