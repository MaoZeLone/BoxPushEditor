# 流程管理器 · 技术策划案

代码：局外 `UBoxGameInstance`，局内 `ABoxGameMode`  
一个入口，两段职责。不要在 Character 或箱子 Actor 里写开局 / 结算。

---

## 职责

**局外（GI）**

- 选关列表、解锁、下一关
- 存档读写
- 试玩请求（不写档）
- 打开选关图 / 对局图

**局内（GM）**

- 开局：消费请求 → 刷 MatchWorld → 刷人
- 把走 / 撤 / 重开 / 暂停转给 MatchWorld
- 通关：算星、写档（试玩除外）、切 Won
- 回选关、下一关

**不管**

- 格子怎么改（[格子模拟](格子模拟.md)）
- 菜单怎么画（[UI](UI.md) 只消费本系统的数据和事件）

---

## 功能

| 功能 | 行为 |
|---|---|
| 开局 | 先吃 `FBoxPlayRequest`；没有则用 `StartupLevel` |
| 试玩 | `bPlaytest=true`，通关不写档 |
| 暂停 | 切 `Paused` / `Playing`；模拟同时打暂停标志 |
| 重开 | 同一份 `ULevelData` 从头刷，不走选关 |
| 通关 | Goal 全满 → 星级 → `RecordClear` |
| 解锁 | 总表 `bListed` 按 `SortOrder`；第 0 关默认开，其后看上一关是否通关 |
| 下一关 | 当前 SortOrder 之后仍 listed 的最小一行；没有则回选关 |

阶段 `EBoxFlowPhase`：`None` / `Select` / `Playing` / `Paused` / `Won`。

星级：步数 ≤ `ParMoves` → 3；≤ 1.5 倍 → 2；通关 → 1。

## 参数

### GameInstance CDO

| 参数 | 类型 | 默认 / 约定 | 说明 |
|---|---|---|---|
| `LevelCatalog` | 软引用 DataTable | `/Game/Data/DT_LevelCatalog` | 唯一总表 |
| `SelectMap` | 软引用 World | 可空 | 选关关卡 |
| `PlayMap` | 软引用 World | 可空 | 对局关卡；空则同图重开 |

### GameMode CDO

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `DefaultPlayerDef` | 软引用 `UPlayerDef` | `/Game/Characters/DA_Player` | 关卡不选人 |
| `StartupLevel` | 软引用 `ULevelData` | `/Game/Levels/BuiltIn/DA_Level_01` | 无请求时的兜底 |

### 进关请求 `FBoxPlayRequest`（内存，不进 Content）

| 参数 | 说明 |
|---|---|
| `Level` | 直接指向的关卡 DA |
| `LevelId` | 按总表查 |
| `bPlaytest` | true 则通关不写档 |

### 选关卡片 `FBoxSelectEntry`（只读拼出来）

`LevelId`、`DisplayName`、`SortOrder`、`ParMoves`、`bUnlocked`、`bCleared`、`BestMoves`、`BestStars`。

总表行字段见 [关卡数据](../数据/关卡数据.md)，不在本系统重复定。
