# 程序化地形 · 技术策划案

代码：`ABoxMatchWorld` 用 Instanced Static Mesh 刷地板 / 墙  
输入是关卡 `Cells[]`，不是手摆墙 Actor。编辑器预览和正式对局应读同一张表现表。

---

## 职责

**管**

- 把 Empty / Floor / Wall 刷成 Mesh
- 格子到世界坐标

**不管**

- 能不能走（规则看地形枚举，不看 Mesh）
- 箱子 / 目标 / 踏板模型（各 `VisualComps`）
- 玩家外观（`PawnClass`）
- 邻接换墙变体（P2，先同一面墙）

---

## 功能

| 功能 | 现状 |
|---|---|
| 刷地板 / 墙 | 有。空格不刷 |
| 换模型只改表 | **未接。** 现在写死引擎 Cube |
| `DA_TileVisual` | 类未建 |
| 邻接自动换墙 | 不做（P2） |

MatchWorld 开局 `RebuildPresentation`：Floor / Wall 各一个 ISM；交互物再 Spawn `ABoxInteractableActor`。

---

## 参数

### 关卡输入（只读）

`ULevelData.Cells[]`：`ETerrainCell` = Empty / Floor / Wall。  
目标不进这个枚举。

### 世界（现写死在 `BoxGrid`）

| 参数 | 值 | 说明 |
|---|---|---|
| `CellSize` | 200 | 一格边长 cm |
| `OriginZ` | 200 | 格子平面 |
| 地板 | 位置 Z-10，缩放 (1.95, 1.95, 0.1) | 占位 |
| 墙 | 位置 Z+100，缩放 (1.95, 1.95, 2) | 占位 |

### 计划中的 `DA_TileVisual`（`/Game/Data/DA_TileVisual`）

| 参数 | 类型 | 说明 |
|---|---|---|
| `FloorMesh` | 软引用 StaticMesh | 空则引擎方块 |
| `WallMesh` | 软引用 StaticMesh | 先同一面墙 |
| `EmptyMesh` | 软引用 StaticMesh | 通常空，不刷 |
| `CellSize` | float | 应替代写死的 200 |
| `FloorMaterial` / `WallMaterial` | 可选 | 可空 |

**不**放 Target / Box / Player。换皮只改这份，不改关卡、不改规则。
