# 表现 · 技术策划案

逻辑已经落格，表现再跟。薄：短插值、状态显隐、四个音、弹簧臂相机。

---

## 职责

**管**

- 人、箱子从旧格插值到新格
- `VisibleInStates` 随 `CurrentState` 显隐（目标 Occupied Glow 等）
- 角色动画读 `State.Walking` / `State.Pushing`
- 对局相机

**不管**

- 格子规则、胜负计算
- 骨骼动画资源管线（官方用人形几何占位即可）
- 编辑器视口（复用刷 Mesh，但是编辑器系统）

---

## 功能

| 功能 | 状态 |
|---|---|
| 格子移动短插值 | 有。`StepDuration` 默认 0.18s |
| 一步未播完锁输入 | 有。`Status.StepLocked` |
| 目标 Occupied Glow | 定义可配 `VisibleInStates`；官方 DA 默认带 Glow 节点 |
| Niagara / Audio 组件真正播放 | 数据有字段，空则跳过，**播放未接** |
| 四个音（走 / 推 / 胜 / 按钮） | 计划 `DA_Audio`，未建 |
| 相机按本关包围盒居中 | **未做**。弹簧臂现在写在 Character 上 |

回程箱：主阶段播完再播一截回程插值（`FlushImmediateReturns`）。

---

## 参数

### 对局 `ABoxMatchWorld`

| 参数 | 默认 | 说明 |
|---|---|---|
| `StepDuration` | 0.18 | 一步插值秒数；人、箱子共用 |

交互物 Actor 内 `InterpDuration` 目前同样 0.18。

### 交互物视觉

见 [交互物运行时](交互物运行时.md) 的 `VisualComps`。表现系统只读 `CurrentState` + `VisibleInStates`。

### 计划 `DA_Audio`（`/Game/Data/DA_Audio`）

| 参数 | 何时播 |
|---|---|
| `Move` | 人走进邻格 |
| `Push` | 箱子被推动 |
| `Win` | 胜利 |
| `Button` | 菜单按钮 |

空则跳过。不要为四个音开 DataTable。
