# 格子模拟 · 技术策划案

代码：`UBoxGridSim`  
玩法真相。一次有效输入 = 一步。先改格子，再让表现播。

人侧只传入：**方向** + **这帧允不允许推（`bCanPush`）**。不读角色 Tag，不读 `CurrentState` 决定能不能推。

---

## 职责

**管**

- 四向走；墙 / 空洞忽略（不当一步）
- 前一格挡人且带 Pushable → 尝试推
- Slide / Return
- 全 Goal 占满则胜
- 发出模拟事件
- 撤销 / 重开用的格子快照

**不管**

- 角色这帧有没有 Move / Push 许可（[角色3C](角色3C.md)）
- 插值、动画、音效（[表现](表现.md)）
- 暂停菜单 UI（[流程管理器](流程管理器.md) 改 phase；模拟只吃暂停标志）

---

## 功能

开局 `BindAndStart`：刷占用状态、算是否已胜、记下初始快照。

### 走一步 `TryPlayerMove`

```
不是四向一步 / 已暂停 / 已胜利 → 拒绝
Dest 不可站（非 Floor）→ 拒绝
Dest 无 BlocksPlayer → 人走进去
Dest 有 BlocksPlayer
    无 Pushable 或 bCanPush=false → 拒绝（不发 Blocked）
    PushTravel==0 → 发 Blocked，人箱子都不动
    PushTravel≥1 → 箱子走 Travel 格，人进 Dest
```

成功才加步数、记撤销、刷 Goal / 踏板占用、判胜。

人永远只进一格。箱子走 `Travel` 格。

### 行程 `PushTravel`

- 默认上限 = `Pushable.Steps`
- 有 Slide → 忽略 Steps，滑到不能进
- 下一格非 Floor → 停
- 下一格 `BlocksPush` → 停；Slide 且 `bStopOnBox=false` 时可从另一只箱子格穿过

### 回程

有 Return 的箱子记下本步开始时的格。`DelayMoves=0`：一步表现完立刻回（`FlushImmediateReturns`）。回不去（家被占）则不回。

### 撤销 / 重开

- 撤销：弹出上一步快照，恢复人、实例、步数、胜负
- 重开：回到 `BindAndStart` 的初始快照，清撤销栈

设计写「记格子差分」。实现目前是整份运行时快照，格子 5–20，可接受。

## 参数

### 入口

| 参数 | 类型 | 说明 |
|---|---|---|
| `Dir` | FIntPoint | 必须是四向之一：`(±1,0)` 或 `(0,±1)` |
| `bCanPush` | bool | 人侧 `CanPerform(Ability.Push)` |

### 运行时

| 参数 | 默认 | 说明 |
|---|---|---|
| `MoveCount` | 0 | 有效步数 |
| `bWon` | false | 全部 Goal 被匹配 Folder 的 Pushable 占满 |
| `bPaused` | false | true 时拒绝走 / 推 / 撤 |

### 模拟事件（发给定义 `States.EnterOn`）

| 事件 | 何时 |
|---|---|
| `Pushed` | 普通推，箱子开始动 |
| `SlideStart` | 有 Slide 的推 |
| `Blocked` | 要推但 Travel=0 |
| `Arrived` | 这一步落定 |
| `Returned` | 开始回原位 |
| `Pressed` / `Released` | Goal / 踏板占用变化 |

### 一步结果 `FBoxStepResult`（给表现）

| 参数 | 说明 |
|---|---|
| `bApplied` | 格子改没改 |
| `bPushed` | 这一步有没有推箱子 |
| `bWon` | 改完是否通关 |
| `PlayerFrom` / `PlayerTo` | 人的格子 |
| `Moves[]` | 实例 From/To/`NewState` |
