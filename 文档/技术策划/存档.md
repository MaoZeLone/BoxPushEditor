# 存档 · 技术策划案

代码：`UBoxSaveGame`  
键是 `LevelId`。不写回 `ULevelData`。试玩、重开中途退出都不污染进度。

---

## 职责

**管**

- 每关是否通关、最少步、最高星
- 主音量

**不管**

- 关卡内容、推荐步数（那些在关卡 DA）
- 对局里箱子当前在哪
- 试玩成绩

流程管理器局外写；对局只在非试玩通关时调 `RecordClear`。

---

## 功能

| 功能 | 行为 |
|---|---|
| 读档 | GI Init：槽不存在则新建 |
| 写档 | 通关、改音量、Shutdown |
| 通关记录 | 只升不降：`bCleared=true`；更好的步数 / 星级才覆盖 |
| 音量 | 0–1，立刻生效并写槽 |

槽名：`BoxPushSave`，index 0。

---

## 参数

### `UBoxSaveGame`

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `Levels` | `TMap<FName, FBoxLevelRecord>` | 空 | 键 = `LevelId` |
| `MasterVolume` | float | 1 | 主音量 |

### `FBoxLevelRecord`

| 参数 | 类型 | 说明 |
|---|---|---|
| `bCleared` | bool | 是否通过 |
| `BestMoves` | int32 | 最少步；0 表示还没有 |
| `BestStars` | int32 | 1–3 |

设置音量可以和关卡进度同一份，不要和关卡资产混。
