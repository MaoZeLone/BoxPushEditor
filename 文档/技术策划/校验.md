# 校验 · 技术策划案

不是玩法系统。它是数据能不能进流程管理器、能不能上架 / 试玩的门。  
DA 仍可保存；错误则 `bListed` 不能为 true，不能试玩。

---

## 职责

**管**

- 对着总表、单关、交互物定义、角色定义跑规则
- 产出 `FLevelValidationIssue`（错误 / 警告、文案、相关格子）

**不管**

- 好不好玩（策划 PIE）
- 运行时每一步再验一遍玩法（进关前可再跑；非法关选关本来看不到）

谁调用：编辑器保存 / 上架 / 试玩前必跑；运行时进关前可选。

---

## 功能

| 入口 | 查什么 |
|---|---|
| `ULevelData::Validate` | 单关几何、出生、实例、Pushable=Goal、同格双 Blocking |
| `ULevelCatalogLibrary::ValidateCatalog` | 行名、重复 Id、LevelAsset 能加载且 LevelId 一致 |
| `ValidateLevelForListing` | 单关 Validate + 总表有这一行 |
| `UInteractableDef::Validate` | Id、表现树、状态、逻辑同类一条、Slide/Return 需 Pushable |
| `UPlayerDef::Validate` | 四件套、ActionSet 必要行、InputTag 对得上 Native |

箱子数按 **有没有 `UPushableLogic`**，目标按 **有没有 `UGoalLogic`**，不看名字是不是 `Box_`。

---

## 参数

### 一条问题 `FLevelValidationIssue`

| 参数 | 说明 |
|---|---|
| `bError` | true = 拦住上架 / 试玩；false = 警告仍可上架 |
| `Message` | 中文 |
| `Cells[]` | 可高亮的格子（编辑器 P1） |

### 单关错误

- `LevelId` 空；宽高不在 5–20；`Cells.Num() != W*H`
- 出生点在地图外或不是 Floor
- 实例缺 Id / 重复 Id；缺 Definition 且无法加载
- 实例在墙 / 空洞上
- Pushable 数 ≠ Goal 数，或 < 1
- 同一格两个 Blocking

### 单关警告

- 最外圈没有封闭的墙
- `ParMoves < 1`
- `DesignerNote` 空

### 定义 DA 错误

- `DefinitionId` 空，或资产名不是 `DA_<Id>`
- Visual `CompId` 重复、ParentId 非法、成环
- `VisibleInStates` 引用未知 StateId
- Logic 同类多于一条；Slide/Return 没有 Pushable
- States 无 `bDefault` 或不止一个；同一事件被两条占用
