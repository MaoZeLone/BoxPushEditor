# 交互物运行时 · 技术策划案

代码：定义 `UInteractableDef`，场景 `ABoxInteractableActor`  
场景里同一种 Actor。换种类只换定义 DA，不加新 Actor 类。墙 / 地板不是交互物。

---

## 职责

**管**

- 这种东西长什么样（`VisualComps`）
- 有哪些逻辑（`LogicComps`，有就生效）
- 会进哪些表现状态（`States`）
- 按模拟事件切 `CurrentState`，按 `VisibleInStates` 显隐

**不管**

- 这一格能不能走（地形 + Blocking，由地图 / 模拟问定义）
- 每种箱子一个蓝图 Actor
- State Tree、`VisualId`、`DT_Interactable`

逻辑组件**不**读 `CurrentState` 决定能不能推。

---

## 功能

官方五份：普通箱、推到底、往回、目标、踏板。复制 DA、增删组件 = 新种类。

可推箱子最小配方：**Blocking + Pushable**。

| 种类 | LogicComps | 行为 |
|---|---|---|
| `DA_Box_Normal` | Blocking + Pushable(Steps=1) | 一次推一格 |
| `DA_Box_Slide` | + Slide | 忽略 Steps，滑到停 |
| `DA_Box_Return` | + Return | 推完回原位 |
| `DA_Target` | 只 Goal | 不挡；叠上匹配箱子算入胜 |
| `DA_Pedal` | 只 Pedal | 压下切 Pressed；`EventId` 先发后接 |

表现最小树：`Root(Empty) → Body(Mesh)`。Mesh 空则引擎方块。目标可再挂只在 `Occupied` 显示的 Glow。

## 参数

### 定义 `UInteractableDef`

| 参数 | 类型 | 说明 |
|---|---|---|
| `DefinitionId` | FName | 创建后不改。资产名 `DA_<Id>` |
| `DisplayName` | FText | 调色板 |
| `Folder` | FName | `Box` / `Target` / `Pedal`。Goal 用它认箱子 |
| `DesignerNote` | FString | 仅编辑器 |
| `VisualComps[]` | Instanced | 表现树 |
| `LogicComps[]` | Instanced | 同类最多一条 |
| `States[]` | 结构数组 | 恰好一个 `bDefault` |

路径：`/Game/Interactables/`。Primary Asset Type：`InteractableDef`。

### 表现组件基类

| 参数 | 说明 |
|---|---|
| `CompId` | 本 DA 内唯一 |
| `ParentId` | 父节点 CompId，空 = 挂 Actor |
| `RelativeLocation` / `Rotation` / `Scale` | 相对父 |
| `VisibleInStates` | 空 = 全显示；有值则只在这些 `StateId` 下显示 |

子类额外字段：`UVisualMeshComp` 的 `Mesh`、`MaterialOverride`；Niagara / Audio 资产可空（空则跳过播放）。

### 逻辑组件

| 组件 | 参数 | 默认 | 说明 |
|---|---|---|---|
| Blocking | `bBlocksPlayer` | true | 挡人 |
| | `bBlocksPush` | true | 挡被推的箱子 |
| Pushable | `Steps` | 1 | 一次连走几格，≥1 |
| Slide | `bStopOnBox` | true | 前方另一只箱子则停 |
| Return | `DelayMoves` | 0 | 再过几步才回；0 = 本步表现完立刻回 |
| Goal | `RequiredFolder` | `Box` | 谁停上面算入胜；空 = 任意 Pushable |
| Pedal | `AcceptFolder` | `Box` | 谁能压；空 = 箱子或玩家 |
| | `EventId` | 空 | 压下发给事件系统；现只切状态 |

Slide / Return 必须同时有 Pushable。

### 状态 `FInteractableStateDef`

| 参数 | 说明 |
|---|---|
| `StateId` | 如 Idle / Moving / Occupied |
| `bDefault` | 出生、复位 |
| `EnterOn[]` | 哪些模拟事件切进这个状态 |

同一事件不要写在两条状态上。
