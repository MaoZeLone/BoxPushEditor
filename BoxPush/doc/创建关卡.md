# 创建关卡

在编辑器里打开 **窗口 → BoxPush 关卡编辑器**。关卡是一份 `ULevelData` 资产，文件名是 `DA_` 加上关卡资产名。新建时会同时在关卡目录表里加一行。没上架的关不会出现在选关里。

## 新建

工具栏点新建。窗口里填：

- **显示名：** 选关和标题上看到的名字。不能空。
- **关卡资产名：** 只能用字母、数字、下划线，不能和已有关卡或目录行重复。资产会存成 `DA_这个名字`，创建后不再改。
- **设计备注：** 可以空着，只给自己看。

点创建。网格默认能改，宽高各自在 1 到 20。缩小到会裁掉玩家或物体时，会先问是否继续。

## 窗口怎么用

左边是关卡列表，可以调顺序。中间是预览。下面是可放置的内容。右边是这一关或选中物体的详情。

打开时在 **普通模式**。要铺格子再切到 **笔刷模式**。

| 场合 | 操作 |
| --- | --- |
| 笔刷模式 | 左键铺地板、墙、空洞、玩家或交互物，按住可拖。右键先擦物体，没有物体时墙变地板、地板变空洞。Ctrl+Z 撤销，Ctrl+Y 重做 |
| 普通模式 | 左键点选，再点同一格切换叠在一起的物体。按住拖到别的格子，或拖坐标轴。右键擦这一格，Delete 删除当前选中。再点当前关卡，右边回到这一关的配置 |
| 试玩 | WASD 移动，Z 撤销，Y 重做，R 重开，Esc 停止 |
| 看镜头 | 中键平移，Alt+左键旋转，滚轮缩放，F 或「归位」回到俯视 |

地板能走。墙和空洞不能走。玩家出生点在格子上，朝向用上、右、下、左，和交互物同一套：0 上、1 右、2 下、3 左。开局和重开按这个方向站。走一步之后，人转向正在走的方向。

选中一只交互物时，可以改它这一关的朝向。定义上勾了「可实例重载」的参数，也能只改这一只，例如返回箱等多步再回家。

## 保存、校验、上架

保存会写当前关卡，以及关卡目录表。

校验出 Error 时不能试玩，也不能上架。半成品可以先保存。没有 Error 后再勾上架，正式选关才能打到。警告不挡试玩和上架。

试玩在这个窗口里进行，不进 PIE，不写通关存档。停止后，关卡回到试玩前的样子。

## 删除

右边关卡详情里点 **删除关卡**。先确认。选否什么都不动。选是之后，先从关卡目录去掉对应行并保存目录，再删除关卡资产。找不到目录时不会删。目录行已经去掉、资产却删不掉时，状态栏会说明。
